# Animora — releases

Installers of the **Animora** desktop apps (macOS · Windows · Linux). Download the newest one from the [Releases](../../releases/latest) page, or from **https://animora.uz/download**.

| | file |
|---|---|
| macOS 15+ (Apple Silicon and Intel) | `Animora-macOS.dmg` |
| Windows 10 / 11 (64-bit) | `Animora-Setup-win-x64.exe` |
| Linux x64 / arm64 | `Animora-linux-*.AppImage` · `Animora-linux-*.deb` |

**First launch.** macOS: move the app to *Applications*, then Control-click it → *Open*. Windows: in the SmartScreen window choose *More info* → *Run anyway* (the apps are not code-signed yet).

The apps check this repository for a newer release and tell you when one is out. Phones: Google Play / App Store — see animora.uz/download.
